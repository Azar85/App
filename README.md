# کلوپ حامد — شعبه چهارده‌متری

نسخه اندروید سایت https://cluphamed.ir/ مشتق‌شده از اپ تأییدشده سواران.

- نام اپ: کلوپ حامد
- شناسه نصب اندروید: ir.cluphamed.club (مستقل از نسخه سواران)
- ثبت سفارش تنها از طریق سایت اصلی است و کد سفارش به سامانه فعلی شعبه وارد می‌شود.

## ساخت APK آزمایشی

در GitHub به Actions بروید و Build Cluphamed 14m APK شاخه cluphamed-main را باز کنید. پس از موفقیت، ClupHamed-14m-test-apk در بخش Artifacts قابل دانلود است. این نسخه برای تست روی گوشی است و انتشار نهایی به امضای اختصاصی و بررسی شرایط فروشگاه نیاز دارد.

## وضعیت
کامپایل موفق اثبات تست سفارش در این شعبه نیست؛ سفارش باید با گوشی و پنل شعبه چهارده‌متری آزمایش شود.

## نسخه آماده‌سازی فروشگاهی 1.1.0
API 36 هدف گرفته می‌شود. در Actions علاوه بر تست APK، فایل AAB/APK **امضانشده** ساخته می‌شود؛ برای انتشار حتماً باید با کلید امن ثابت توسعه‌دهنده امضا شود. کلید یا رمز را در GitHub قرار ندهید.
