# کلوپ حامد سواران — اپلیکیشن اندروید

وب‌اپ بومی اندروید متصل به https://cluphamedsavaran.ir/
نام پکیج: `ir.cluphamed.savaran`

## دریافت APK آزمایشی
وارد تب **Actions** شوید، گردش‌کار **Build test APK** را باز کنید، روی **Run workflow** بزنید و بعد از اجرای موفق، از بخش **Artifacts** فایل APK را دریافت کنید.

این APK برای **تست روی گوشی** است، نه انتشار نهایی بازار/مایکت. برای انتشار باید امضای اختصاصی (keystore)، تست واقعی سفارش و پرداخت، سیاست حریم خصوصی، عکس‌های واقعی و تأیید مجوز انتشار محتوای آرشیو آماده شود.

فایل‌ها با Android Gradle Plugin 8.7.3، Gradle 8.9، Java 17 و Android SDK 35 ساخته می‌شوند.
